LEARNINGLOBAL — VOCABULAIRE FRANÇAIS B1

Αποσυμπιέστε το ZIP. Ανεβάστε όλα τα αρχεία στο root ενός GitHub repository (π.χ. vocabulaire-french-B1). Στο Settings > Pages επιλέξτε Deploy from a branch, main, / (root), Save.
Ανοίξτε τη διεύθυνση HTTPS που δίνει το GitHub Pages.

Android / Chrome: Εγκατάσταση εφαρμογής ή Προσθήκη στην αρχική οθόνη.
iPhone / iPad / Safari: Κοινοποίηση > Προσθήκη στην οθόνη αφετηρίας.
Υπολογιστής / Chrome ή Edge: εικονίδιο εγκατάστασης στη γραμμή διεύθυνσης ή κουμπί Installer l’application.

Πρώτη φόρτωση με σύνδεση: περιμένετε το μήνυμα διαθεσιμότητας εκτός σύνδεσης. Η πρόοδος αποθηκεύεται τοπικά ανά συσκευή και browser. Δεν συγχρονίζεται μεταξύ συσκευών.

Για μελλοντικές ενημερώσεις αλλάξτε το CACHE στο service-worker.js (v2, v3…).
